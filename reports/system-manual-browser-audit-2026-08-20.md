## 验收环境

- 环境：当前工作区 Docker Compose，入口 `http://127.0.0.1:8081`。
- 身份：专用 E2E 账号；凭据只在执行时读取，没有写入日志或报告。
- 浏览器：Codex 内置浏览器，中文界面，实际视口约 812 × 708。
- 源码同步：后端、前端与文档工具修改均通过 `make hot-update` 应用到容器；没有用静态页面或 mock 替代实机。
- 测试原则：按真实用户旅程连续操作，既检查页面是否能打开，也检查输入、提交、流式状态、跨模块跳转、错误反馈和持久化结果。

## 修复闭环

1. **Agent 文本流丢失**：公开事件类型此前把 Enum 转成错误字符串，导致 `text_delta` 被过滤。改为使用 Enum value，并增加前后端事件投影回归。
2. **空工具目录造成 37 秒循环**：没有业务工具时不再向模型暴露空的发现桥，实机从 37.31 秒、四轮空 `tool_search` 降至 8.85 秒、零空工具卡片。
3. **Agent 目录可读性**：过滤内部发现桥，保留工具元数据，统一用户可见名称；文档工具显示为“文档生成”，不暴露 MCP 实现名。
4. **Skills 目录 503**：修复跨 schema 表名解析；真实 Agent Studio Skills 请求恢复 200。
5. **知识库整页崩溃**：补齐 `useCallback` 导入；文档管理与版本历史重新实机通过。
6. **用户创建整页崩溃**：FastAPI 数组错误不再直接作为 React child 渲染；增加必填字段本地校验和稳定错误提取。
7. **服务调试错误路由**：虚拟 Assistant 服务直接进入 Assistant；只有外部代理服务才进入 Playground，并先绑定 service id。
8. **模型能力配置混排**：能力编辑器、容量页、用户弹窗等新增中文/英文文案，中文界面不再显示这批英文控件标题。
9. **连接器 UI**：设置页编辑/删除按钮增加可访问名称；Assistant 连接器不再用 emoji 或直接显示 icon URL，统一为真实图片或图标库回退，并为连接/激活/断开按钮补充连接器名称。
10. **DOCX 重复生成**：已有作者正文时规划器跳过第二次 LLM 撰写；实机同类任务从 165.06 秒降至 33.08 秒，文件生成和下载均成功。
11. **产物遮挡对话**：文档产物不再自动展开右侧封面面板；图片仍保留自动预览。
12. **门禁环境确定性**：Agent Eval 子代理注册测试显式声明 test 环境，避免匿名开发开关与启动安全校验冲突。

## 真实任务与性能证据

| 场景 | 实机结果 |
| --- | --- |
| 800–1000 字中文小说 | 总耗时 32.75 秒；首个可见 Token 3.51 秒；首文本 12.55 秒 |
| 解释 Transformer | 总耗时 22.71 秒；首个可见 Token 3.62 秒；首文本 6.03 秒 |
| 长任务停止 | 终态为“已取消”，没有 Provider 400；已发布工具活动闭合 |
| 同一会话停止后续聊 | 成功继续回复，没有重复计费或会话损坏迹象 |
| DOCX 周报 | 总耗时 33.08 秒；首个可见 Token 3.84 秒；首文本 31.23 秒；DOCX 可下载 |
| 空工具 Agent 试跑 | 8.85 秒完成，返回文本，零空 `tool_search`；随后离线评测通过并发布 v1 |
| Provider 连接测试 | Qwen Provider 连接成功，实测 2893 ms |

TTFT 口径是首个前端可见 reasoning summary 或文本 Token。两项普通文本任务均进入 3–5 秒目标；DOCX 的首文本较晚是因为先完成工具产物，首个 reasoning Token 仍为 3.84 秒。

## 已知边界

- 一次要求“两句话”的多轮跟随回复只返回一句，属于模型质量波动；协议、会话和 UI 状态正常。后续应进入通用 Agent cohort，而不是用关键词硬编码修正。
- Playground 没有外部代理服务时显示空选择器，这是当前租户配置的真实空状态；Assistant 已不再被错误导入该页面。
- Skill Creator 在当前本地配置中标记不可用，但 Skills 目录本身已恢复，错误不再是数据库 503。
- Trace 全历史约 20% 错误率包含本轮修复前的故障复现，不能当作新代码的实时错误率。
- 本轮没有执行依赖 `localhost:8080` 的两个活体隔离用例；其余当前 Docker 健康与浏览器旅程由 `make validate`、`make status` 做最终确认。
